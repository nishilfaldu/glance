Glance
Example

See a pull request before you read it.

Glance maps a branch: where the changes sit, and how the changed functions call each other. The edit that doesn't belong stands out on its own.

$ git clone https://github.com/nishilfaldu/glance
$ cd glance/cli && npm install && npm link
Open the example How it works

Repo map

The whole repo on one screen. Changed files open up to show the functions the branch touched. Click one to mark it reviewed.

Call graph

Only the paths that lead to a change. Lines are folders, arrows are calls. Hover a function to trace it.

Run it

Check out a branch and run glance. The page opens on localhost and nothing leaves your machine. Add --working to include uncommitted changes.

How it works

No AI. Glance reads git and parses your code with the TypeScript compiler, so the same branch always gives the same map.

Lines become functions

Every changed line belongs to the innermost function around it. Lines outside any function belong to the file.

Calls connect them

Each call is followed through the file's imports to the function it lands on. A chain through an unchanged helper still connects.

The main change

The largest group of connected functions is the main change. Anything outside it gets a teal number. Tests don't count, since they call everything.

Flags

Rules only read lines the branch added. A flag says what was found, not that it's wrong.

Share it

glance publish --pr puts a secret link in the PR description. Publishing again updates the same link. Only names and calls are uploaded, never code.

Reference

glanceOpen the map on localhost
glance publishUpload it and print a secret link
glance jsonPrint the brief as JSON
--base <ref>Compare against this branch
--workingInclude uncommitted changes
--pr [n]Link it on the pull request

Limits

Functions are found in TypeScript and JavaScript only. Calls on objects (db.insert()) and path aliases (@/lib) aren't followed yet.
